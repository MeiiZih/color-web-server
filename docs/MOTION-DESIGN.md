# ColorLab 動態設計｜2026-09-06

## 方向與來源

- 使用者授權請 Gemini 協助設計；已向 Gemini Flash 提供品牌色、既有介面描述與動態限制，未上傳會員資料、金鑰或原始碼。
- 採用「輕盈紙感」方向；沿用四色 SVG 紙卡，不新增生圖、影片或動畫套件。
- 設計取捨：不採用 1 秒紙卡進場、裁切揭露或等待離場動畫；使用者可立即操作。
- 節奏為 140ms 按壓、280ms 題目／彈窗、440ms 主視覺；主要曲線為 cubic-bezier(.22,1,.36,1)。

## 改動邊界

- `app/motion.css` 在主站、會員／後台、PDF 頁共用；後台資料重繪不套用整頁進場。
- `app.js` 的 render(direction) 僅接收 next / previous 視覺提示；hashchange 事件與其他既有呼叫仍走 page 預設。
- 上／下一題仍依序修改草稿索引、儲存、render、聚焦題目。動畫不延後儲存、不加鎖、不重複提交、不改計分。
- 選答案時原本的 DOM 保留；只有勾選圖示與顏色回饋。進度條不跟題目左右移動。
- 減少動態設定停用進場與過渡；內容預設可見，沒有捲動解鎖或無限裝飾動畫。
- PWA 公開介面快取納入 motion.css，未變動會員資料／API 快取政策。
- 手機紙卡增加兩側旋轉留白，避免 320px 畫面溢出。
