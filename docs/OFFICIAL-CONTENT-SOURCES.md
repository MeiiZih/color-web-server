- 使用官方 RSS（若有）、API（若有），其他來源再測試公開列表解析與使用限制。衛福部已確認提供 [官方 RSS](https://www.mohw.gov.tw/cp-2661-6125-1.html)，其他單位尚未驗證可穩定自動擷取。

- 過期活動自動停止推播；沒有明確活動日期或資格的項目，不自行猜測，改為草稿。地區與適用年齡不得省略。

- 使用 ColorLab 自有卡片圖樣；未取得授權不整篇搬運第三方文章、海報或標誌。
- 若要求電腦關機仍更新，需真正部署雲端排程；不能以本機 Codex 提醒或 Render 休眠程序內的計時器冒充可靠雲端排程。排程與權限需部署後實跑確認。

## 現有資料流與最小接點（已讀碼）

`color-web/app/app.js` 啟動時呼叫 `GET /api/homepage`，回傳陣列按 `type=news/common` 分類成首頁卡片。`app/account.mjs` 的內容管理同樣依賴這組讀取與 CRUD。資料由 `Server/models/Homepage.js` 儲存；目前只有手動標題、圖片、連結、說明與時間，沒有來源、到期、審核或同步狀態。

適合維持現有公開 API 的陣列契約，增加獨立來源同步服務與內容來源欄位，不重寫測驗或帳號流程。雲端排程、來源解析、管理員審核會是新功能，不能假裝只加一個定時器就已完成。

目前提問：直接自動上架官方標題／日期／連結、重要欄位變更先確認，或全部存為草稿由管理員核准。尚未收到回答。
