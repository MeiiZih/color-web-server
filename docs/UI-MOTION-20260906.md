# ColorLab 角色與資訊圖片修正

## 本次範圍

- 保留原報告四角色及現有首頁視覺，新增共用 SVG 分層呈現；不是重新畫一套角色。
- 紅色局部伸縮、黃色手臂揮動、綠色點頭、藍色輕微傾頭與眨眼。12 秒循環、錯開節奏，與答案內容無關。
- 手機與桌面測驗封面、作答陪伴區使用相同比例畫布；提供暫停及減少動態支援。
- 原始圖片不修改；只替換 app.js 的角色產生介面及其 CSS，問卷、計分、登入、會員資料不變。
- 官方圖片仍優先，缺圖或讀取失敗時使用 900×600 WebP 插畫，每張約 43–75 KB，標示 AI 主題示意、非官方海報。
- 靜態入口的 manifest、Apple 安裝中繼資料與離線快取清單同步更新。不把前端合回休眠後端。

## 設計與圖片來源

Gemini 提供角色局部伸縮及揮手的動作建議；實際分層動畫由專案程式實作。四張主題插畫使用 Codex 圖片生成工具產生，**並非 Nano Banana 產圖**。

共用生成方向：橫式 3:2、溫暖奶油白、低飽和莓紅／鼠尾草綠／奶油黃／藍色、紙材與鉛筆紋理、友善成人心理健康主題；沒有文字、商標、官方徽章或可被誤認為研究數據的標示。

| 檔案 | 主題提示 |
| --- | --- |
| content-support.webp | 兩位成年人隔著小桌子溫和交談與傾聽，室內植物，不呈現診斷或治療承諾。 |
| content-workshop.webp | 三位成年人共同進行情緒拼貼與自我探索工作坊，桌上色紙與畫具。 |
| content-reading.webp | 成年人在安靜閱讀角落看書，扶手椅、茶與植物，適合心理健康閱讀文章。 |
| content-research.webp | 開放的研究筆記與放大鏡，抽象色塊與圖形，沒有真實數值、研究結果或文字。 |

素材放在 `color-web/assets/images/`，壓縮腳本為 `scripts/prepare-content-art.cjs`。生成原始檔保留於本機，正式網站不依賴本機路徑。

## 連結查核與替代管道

本次逐一 GET 查核 20 筆來源：18 筆收到回應；其中期刊頁出現 Cookie 檢查，2 筆生命線總會頁在本機逾時。逾時不代表活動過期，因此沒有擅自下架或改寫原始來源。

- [生命線總會公告](https://life1995.org.tw/?aid=301&iid=169&page_name=detail)所列的[官方 LINE](https://page.line.me/093wgvxu?openQrModal=true)用作青少年服務的替代窗口。
- 一般協談另外提供[新北生命線協談說明](https://www.1995.org.tw/volunteer.php)，明確標示不同單位，不假裝是總會原公告。
- 期刊遇到 Cookie 檢查可查看[同篇 PubMed 摘要](https://pubmed.ncbi.nlm.nih.gov/41772060/)，不把摘要當成全文。

## 尚有限制

- iPhone 的主畫面安裝、Safari 工具列是否消失仍需實機確認；網頁 CSS 不能強制隱藏瀏覽器工具列。可參考 [Apple Web App 設定](https://developer.apple.com/library/archive/documentation/AppleApplications/Reference/SafariWebContent/ConfiguringWebApplications/ConfiguringWebApplications.html)。
- 第三方網站本身的逾時、Cookie 驗證不能由 ColorLab 修復，已提供經查核替代入口。
- 每週摘要寄信為先前完成的本機流程，後台勾選審核發布區仍未完成；本次不會自動發布或刪除公開資訊。
